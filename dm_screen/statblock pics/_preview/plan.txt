# Handwritten stat sheet clarifications

Source: photos in [`dm_screen/statblock pics/`](dm_screen/statblock pics/), clarified in Q&A. Use these when filling [`dm_screen/dnd_advent_stat_blocks.json`](dm_screen/dnd_advent_stat_blocks.json) and related armory data. Separate from the UI work in the [Populate panelTemplate](populate_paneltemplate_034fbf47.plan.md) plan.

## Locked unit / weapon fixes

- **Naja (IMG_6869):** Rank 1 Plasma Sniper MK1 crit dmg = **3**
- **Stun Lancer (IMG_6878):** AC = **16** for Stun / Heavy / Elite; Heavy Lancer Mag Rifle MK1 = **same stats as Stun Lancer Mag Rifle MK1**
- **Rocketeer (IMG_6881):** WIS = **8**; Adv/Elite rocket lines use the single **Advent Armory Rocket** (IMG_6900): `1d8 Blunt, 60 range, 10 radius, shred 1`
- **Shieldbearer (IMG_6886):** Skills = **Perception** (proficient); Senses = **Passive Perception**; PP = **10 + Perception** (WIS mod ± proficiency when proficient)
- **Priest (IMG_6888):** Initiative = **2**

## Armory / AoE rules

- **AP** = **Armor Piercing** (e.g. Mag Rifle MK4 “2 AP”, Target Focus “AP 4”)
- **Micro Missile** (IMG_6894 / IMG_6900): **3 separate missiles**, each with a **10 ft radius**
- **Flame Thrower** (IMG_6899): **30 ft cone**; Burn DC still open as formula detail later if needed
- **Stun Lance** Stun DC = **8 + STR mod + proficiency**

## Skills model

- Skills list = **proficient skills**, and when the sheet writes a modifier, **include that modifier**
- Do not invent modifiers when the sheet only names the skill (compute from ability + proficiency when needed)
